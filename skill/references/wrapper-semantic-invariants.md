# Wrapper semantic invariants (normative draft)

JSON Schema validates types and local gates. A future execution owner must separately implement/review these cross-record checks; static examples do not demonstrate an implementation.

1. All source/claim/fact/calculation/cell/rule IDs resolve, with unique definitions. Material statements have original evidence or explicit inference/assumption basis; no fabricated locator or authority.
2. Three view slots are exactly 1, 2 and 3; selected master IDs are distinct and match the frozen route. Preserve all requested masters, including abstaining slots. Team/organization evidence cannot become personal authorship.
3. Freeze receipt/packet/method/prompt/raw-response hashes resolve to exact bytes. A frozen route precedes every invocation and is generated without outcomes/opinions. Trait fact IDs are observable and admissible, not conclusions.
4. Adapter reference SHA-256 matches the unchanged accepted result bytes and strict schema. Every available panel points to that exact hash and the corresponding existing JSON pointer. Missing adapter means missing panels; no synthetic passing score.
5. Complete/partial/abstain states reflect actual source/calculation/model/orchestration execution. Unknown model identity blocks a claimed completed invocation. Retries/corrective rounds are recorded separately and cap at three for a stable task.
6. Historical sources/facts are proven public by 2025-12-31T23:59:59Z, not fiscal-period or current-page dates; unknown/mutable/post-cutoff sources are absent from worker bytes. Native rule authenticity and public availability are distinct gates.
7. Quantitative values have reviewed model/unit/period/domain semantics. Assumptions stay labelled. Financing, currencies, ADR ratios, security class and dilution reconcile. Missing is null. A five-year value does not become a short-term price target.
8. No target-price average, celebrity vote, universal master score, model-confidence probability, 13F private intent/full-portfolio/realized-profit inference, or unapproved external action. Source catalogue score and empirical success remain distinct from method fit and company analysis.

The complete mandatory gate list is `schemas/semantic-preflight-contract.v0.1.json` (S01–S15). Its cash-flow semantics, per-view integration accounting and single-context isolation requirements are normative. The model emits only the specialized one-view analytical response; the trusted controller enriches it with exact runtime/hash receipts before assembling three slots. This is a contract, not an implemented or passed runtime validator.
