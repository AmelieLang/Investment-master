# GitHub investment method project catalogue

This candidate restores the readable 20-project comparison omitted from the current source-only bundle. It preserves the accepted V1 source scores and ranks. It is prepared for independent review and has not been published by this audit.

## Scope and dates

The popularity table is the highest-star 20 in a bounded, eligible, accessible and lineage-deduplicated research sample. The review admitted 29 eligible projects from 71 metadata-verified and scope-screened repositories. The 483 first-page search hits were discovery leads. This is not an exhaustive or current global GitHub ranking.

Stars were sampled from 2026-10-12 16:22 to 16:25 UTC. Scores are subjective judgments from static inspection of the pinned commits shown in each detailed record. Stars measure popularity, not method quality. Source-quality ranks cover 21 reviewed projects, including one separately labelled supplemental backbone. They are not performance ranks.

## Scores and interpretation

Each criterion is 0–5: C1 method completeness/detail; C2 stock thesis, valuation and quantifiability; C3 differentiated causal mechanisms; C4 substance over persona and evidence discipline. Evidence is given as a rationale plus exact pinned public files in the detailed review. C4 is not a stand-alone count of citations. C3 does not reward contrarianism without a testable mechanism.

Static base /100 = 100 × (20×C1 + 30×C2 + 20×C3 + 15×C4) / 425. The score column reports C1/C2/C3/C4 in that order. Ties use C2, then C4, C1, C3 and stars. These scores do not establish authentic investor views, stock-picking accuracy, or realized returns.

## Selection rationale

The accepted reusable research foundation is finterm. Its strength is evidence-bounded card routing, missing-data stops, causal alternatives and research-output discipline. It is a research backbone, and does not provide a native aggregate investment score or unrestricted buy/sell decision. Its title and routing should not be mistaken for an executable intrinsic-value calculator.

The frozen three-project comparison selected finterm, xbtlin and monarchjuno using source quality plus the reuse gate. xbtlin offers detailed company analysis and numerical valuation/checklist mechanisms, with known arithmetic/verification caveats. monarchjuno offers modular company research, distinct lenses and explicit Actual/Estimated/Assumption labelling. It was the third highest source-ranked license-eligible project.

LI-Jialu was raw source rank 3 and agi-now rank 4, ahead of monarchjuno rank 5. Both lacked a verified reusable license at the reviewed pin. Wechat had a README license claim without the corresponding verified license file. Research eligibility permits inspection; it does not authorize direct prompt/code reuse. None of these license gates changes their original research scores or removes them from the popularity table.

MIT verification only covers the repository notice at the reviewed commit. Third-party extracts, data/API rights and trademarks still require separate review. No unlicensed upstream implementation is copied in this recap.

V1 scored the 20 frozen projects plus finterm. V2 retained the same 21 repositories and commits, then expanded structural coverage to 162 source files and 121 canonical entities. Those entities include organizations, collectives, pseudonyms and operating perspectives; 70 are categorized person names excluding executive perspectives. These are inventory definitions, not 121 authenticated investors or independent strategies.

V2 adds identity reconciliation and mechanism-transfer decisions. It does not supply a new C1–C4 leaderboard, so the V1 source ranks remain unchanged here. UZI's 66 roster records contain shared rule generators, and Questflow's 63 packages include institutions and pseudonyms. Neither package/persona count is a count of independently validated master methods.
